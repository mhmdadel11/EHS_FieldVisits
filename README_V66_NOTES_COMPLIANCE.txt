V66 - إصلاح نسبة الالتزام مع ملاحظات الزيارة

- نسبة الالتزام تبدأ من 92% في الزيارة الجديدة.
- كل ملاحظة تحتوي نصاً تخصم 3% فقط.
- المربعات الفارغة لا تخصم.
- النسبة تتغير فور الكتابة.
- زر + بجانب كل مربع يضيف مربعاً جديداً.
- زر - يحذف المربع، والنسبة تعود تلقائياً.
- في وضع تعديل الزيارة، يتم استرجاع النسبة الأساسية من النسبة المحفوظة وعدد الملاحظات حتى لا يتكرر الخصم.
- تم رفع رقم cache للملفات لتجنب تشغيل نسخة JavaScript قديمة.
