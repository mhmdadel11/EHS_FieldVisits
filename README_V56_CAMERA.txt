V56 - CAMERA CAPTURE

تمت إضافة تصوير مباشر بالكاميرا في نموذج الزيارة الميدانية.

- زر 📷 تصوير بالكاميرا يفتح كاميرا الجهاز عبر getUserMedia.
- زر 📁 اختيار صور يفتح ملفات الجهاز.
- يمكن التقاط عدة صور لنفس الزيارة وإضافتها مع الصور المختارة من الجهاز.
- الصور تظهر كمعاينة قبل الحفظ مع إمكانية حذف أي صورة.
- على الهاتف يتم طلب استخدام الكاميرا ويفضل استخدام الكاميرا الخلفية.
- صور الكاميرا يتم تصغيرها إلى عرض أقصى 1600px وتحويلها إلى JPG بجودة مناسبة لتقليل حجم الرفع.
- يجب تشغيل الموقع عبر HTTPS لاستخدام الكاميرا المباشرة (localhost HTTPS مناسب للتجربة، والإنتاج يجب أن يكون HTTPS).
- لا يوجد تغيير في API الحفظ: الصور تستمر بالإرسال كـ Images متعددة إلى /api/visits.
